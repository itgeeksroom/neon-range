# Mission 01 — Find the Door

**Difficulty:** Beginner

## Objective

Discover what service the NovaCorp lab exposes.

## Concepts

### IP address
A network address for a machine or service.

### Port
A numbered network entry point used by an application.

### HTTP
The protocol browsers and web APIs commonly use to communicate.

### Reconnaissance
Collecting information about a target before attempting deeper access.

## Safe scope

Only use the NEON//RANGE lab services running on your own machine.

## Mission

1. Start the lab.
2. Visit `http://localhost:8080`.
3. Open `http://localhost:8080/docs`.
4. Identify the endpoints exposed by the training application.
5. Ask: which endpoints look like they should not be public?

## Success condition

You can explain:

- which port the training API uses
- what service is listening there
- which endpoint appears sensitive
- why exposing internal application information increases risk
